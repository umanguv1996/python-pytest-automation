# Python Pytest Automation Framework

A production-ready test automation framework built using **Python**, **Pytest**, **Playwright** (UI), **Requests** (API), and **Locust** (Performance), featuring continuous integration via **GitHub Actions**.

## Tech Stack
* **Language:** Python 3.10+
* **Test Runner:** Pytest
* **UI Automation:** Playwright
* **API Testing:** Requests
* **Load Testing:** Locust
* **CI/CD:** GitHub Actions

## Execution
```bash
pytest --html=reports/report.html --self-contained-html
